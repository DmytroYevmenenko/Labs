# Сценарії використання (Gherkin)

```gherkin
Feature: Завершення поїздки та розрахунок вартості

  Background:
    Given авторизований користувач має активну поїздку в RENTAL з end_time = NULL
    And самокат не стоїть на станції (station_id = NULL)

  Scenario: Успішне завершення поїздки на вільній станції
    Given на обраній станції кількість самокатів менша за capacity
    When користувач завершує поїздку на цій станції
    Then система ставить station_id самоката рівним id обраної станції
    And система заповнює end_time та рахує total_cost у RENTAL
    And платіжний шлюз підтверджує проведення оплати

  Scenario: Спроба завершення поїздки на переповненій станції
    Given на обраній станції кількість самокатів дорівнює capacity
    When користувач намагається завершити поїздку на цій станції
    Then система не завершує поїздку на цій станції та повідомляє, що вільних місць немає
    And запис у RENTAL лишається з end_time = NULL, а station_id лишається NULL

  Scenario: Помилка оплати при завершенні поїздки
    Given на обраній станції є вільне місце (кількість самокатів < capacity)
    When користувач завершує поїздку, але платіжний шлюз відхиляє оплату
    Then система повідомляє про помилку оплати та дає повторити спробу оплати
    And користувачеві не потрібно заново обирати станцію для повторної спроби

  Scenario: Зупинка поїздки при критичному розряді батареї
    Given під час активної поїздки battery_level самоката падає до 0%
    When система фіксує розряд батареї до 0%
    Then система завершує поїздку, заповнюючи end_time та рахуючи total_cost у RENTAL
    And поле station_id самоката залишається NULL до приїзду сервісу
